# Multi-Page Personal Portfolio

A responsive, multi-page personal portfolio website built with HTML, CSS, and JavaScript to showcase my background, web development projects, and interactive tools.

**Live Demo:** https://devbystan.github.io/multi-page-portfolio

---

## Pages & Features
* **Home (`index.html`):** Clean landing page introducing my work, skills, and featured highlights.
* **About Me (`about-me.html`):** Overview of my background, developer journey, and technical skills.
* **Projects (`projects.html`):** Showcase of selected projects with visuals and description.
* **Interactive Planner (`planner.html`):** Built-in interactive planner tool.
* **Contact (`contact.html`):** Contact information and form.

---

## Built With 
* **HTML5** --- Semantic multi-page structure
* **CSS3**  --- Custom layouts, responsive styling, and visual design (styles.css , planner.css)
* **JavaScript (ES6+)** ----- Interactive functionality and DOM manipulation (script.js , planner.js)

---

## Project Structure

```text
multi-page-portfolio/
|-- index.html             # Main landing page
|-- about-me.html          # Bio and background 
|-- projects.html          # Portfolio projects page
|-- planner.html           # Interactive planner 
|-- contact.html           # Contact information and form
|-- styles.css             # Global stylesheet
|-- planner.css            # Stylesheet for the planner page
|-- script.js              # Main JavaScript functionality
|-- planner.js             # Logic for the interactive planner
`-- *.jpg / *.png          # Portrait and project images.
```
